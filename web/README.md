# Trading V2 dashboard preview

This is a standalone, static UI prototype. Open `index.html` directly in a modern browser; no Node.js, package install, server, or API key is required.

**Important:** all displayed candles and metrics are deterministic illustrative demo data. This preview has no live market-data connection and cannot submit orders. The next integration step is to connect validated market-data and analysis API contracts from the Rust domain layer.
